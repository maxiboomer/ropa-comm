ℹ️ Informação: Importe Avaliações de Impacto à Proteção de Dados (PIA) no formato padrão CNIL. As atividades serão automaticamente mapeadas para o padrão LGPD e integradas ao seu Registro de Atividades de Tratamento.

Formato CNIL PIA

Estrutura esperada:

{
  "atividades": [
    {
      "traitement": {
        "nom": "string",
        "finalites": ["string"]
      },
      "fondement_legal": {
        "type": "string"
      },
      "personnes": {
        "categories": ["string"]
      },
      "donnees": {
        "type": ["string"],
        "sensibles": boolean
      },
      ...
    }
  ]
}

Campos mapeados:

  • traitement.nom → Nome da Atividade
  • traitement.finalites → Finalidade
  • fondement_legal.type → Base Legal
  • personnes.categories → Categorias de Titulares
  • donnees.type → Categorias de Dados
  • donnees.sensibles → Dados Sensíveis
  • destinataires → Destinatários
  • duree_conservation → Prazo de Retenção
  • mesures_securite → Medidas de Segurança
  • responsable.nom → Unidade Controladora
Base Legal LGPD

Compatibilidade com GDPR/CNIL:

  • I – Consentimento
  • II – Obrigação Legal
  • III – Políticas Públicas
  • IV – Pesquisa
  • V – Execução de Contrato
  • VI – Exercício de Direitos
  • VII – Proteção da Vida
  • VIII – Tutela da Saúde
  • IX – Legítimo Interesse
  • X – Proteção do Crédito
